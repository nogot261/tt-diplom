# Информационный портал обучения по охране труда

Веб-приложение для назначения сотрудникам учебных курсов, прохождения интерактивных материалов, итогового тестирования и контроля результатов ответственным специалистом.

## Возможности

- авторизация и роли `employee` / `admin`;
- личный кабинет сотрудника со списком назначенных курсов;
- последовательное прохождение учебных разделов с фиксацией прогресса;
- итоговое тестирование с автоматическим расчетом результата;
- история попыток и статус завершения курса;
- назначение обучения сотрудникам администратором;
- сводная отчетность и экспорт CSV;
- журнал ключевых действий;
- локальная SQLite база данных;
- адаптивный web-интерфейс без привязки к операционной системе клиента.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Открыть `http://127.0.0.1:8000`.

Демонстрационные учетные записи:

- сотрудник: `employee@example.ru` / `Employee123!`;
- администратор: `admin@example.ru` / `Admin123!`.

## Тесты

```bash
pytest -q
```

## Структура

```text
app/                 серверная логика, шаблоны и стили
instance/            рабочая SQLite база, создается автоматически
tests/               автоматические тесты
docs/                архитектура, модель данных, ТЗ и инструкции
run.py                точка запуска
requirements.txt      зависимости
```

## Развертывание

Для демонстрации на Linux приложение запускается через Gunicorn:

```bash
gunicorn -b 0.0.0.0:8000 run:app
```

Внешний reverse proxy при необходимости публикует сервис на стандартном порту 80/443. SQLite подходит для демонстрационной и небольшой локальной установки; при росте нагрузки слой хранения может быть заменен на PostgreSQL без изменения пользовательских сценариев.

Техническое задание приведено в `docs/technical_specification.md`.
