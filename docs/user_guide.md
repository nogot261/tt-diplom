# Инструкция пользователя

## Вход в систему

1. Откройте портал в браузере.
2. Нажмите «Войти».
3. Введите адрес электронной почты и пароль.
4. После входа откроется личный кабинет сотрудника.

## Прохождение обучения

В личном кабинете отображаются назначенные курсы, сроки и текущий статус. Откройте нужный курс и последовательно изучите его разделы. После изучения каждого раздела нажмите кнопку подтверждения завершения. Прогресс сохраняется автоматически.

## Тестирование

Итоговый тест становится доступен после завершения обязательных разделов курса. Выберите ответы и отправьте форму. Система рассчитает результат и покажет, достигнут ли проходной балл. При неудовлетворительном результате повторная попытка доступна в соответствии с настройками курса. История попыток сохраняется.

## Статусы

- «Назначено» - обучение еще не начато.
- «В процессе» - часть курса уже пройдена.
- «Завершено» - итоговая проверка пройдена с требуемым результатом.
- «Просрочено» - срок завершения истек.

При возникновении ошибки доступа следует обратиться к администратору портала.
