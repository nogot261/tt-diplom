# Инструкция администратора

## Вход

Администратор входит через общую страницу авторизации. После успешного входа доступны административная панель, назначения и отчетность.

## Назначение курса

1. Откройте раздел «Назначения».
2. Выберите сотрудника.
3. Выберите курс.
4. Укажите срок прохождения при необходимости.
5. Нажмите «Назначить».

Повторное активное назначение одного курса тому же сотруднику блокируется системой.

## Контроль выполнения

На административной панели отображаются сводные показатели и последние назначения. В отчете доступны сотрудник, подразделение, должность, курс, статус, срок, лучший результат и количество попыток.

## Экспорт

В разделе отчетности доступна выгрузка CSV. Файл можно открыть в табличном редакторе или передать в другую информационную систему.

## Обслуживание

Рабочая база SQLite размещается в каталоге `instance`. Перед обновлением приложения необходимо создать резервную копию базы. Секретный ключ и путь к базе задаются через переменные окружения. Для серверного запуска используется Gunicorn, для повторяемого развертывания предусмотрен Dockerfile.

Перед эксплуатацией демонстрационные учетные записи и учебные материалы необходимо заменить данными организации.
